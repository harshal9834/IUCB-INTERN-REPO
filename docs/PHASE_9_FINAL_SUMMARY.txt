API ENDPOINTS SUPPORTED (8 NEW + EXISTING)
═══════════════════════════════════════════════════════════════════════════════

NEW PHASE 9 ENDPOINTS:
1. GET  /campaigns/:id/progress
   Response: CampaignProgress with real-time metrics

2. GET  /campaigns/:id/logs?limit=50
   Response: DashboardLogEntry[] sorted newest first

3. GET  /campaigns/:id/recipients?status=&search=
   Response: RecipientListItem[] with pagination

4. GET  /system-health
   Response: SystemHealth status object

5. POST /campaigns/:id/pause
   Response: DashboardActionResult

6. POST /campaigns/:id/resume
   Response: DashboardActionResult

7. POST /campaigns/:id/cancel
   Response: DashboardActionResult

8. GET  /recipients/:id/certificate
   Response: PDF blob (certificate download)
