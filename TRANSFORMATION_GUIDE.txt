  WHAT SYSTEM AUTO-GENERATES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

For EVERY recipient, system automatically creates:

  ✨ Credential ID
     Format: CRED-2024-00001, CRED-2024-00002, CRED-2024-00003...
     Auto-incremented for each recipient

  ✨ Certificate ID
     Format: CERT-2024-00001, CERT-2024-00002, CERT-2024-00003...
     Auto-incremented for each certificate

  ✨ Registration Number
     Format: REG-2024-00001, REG-2024-00002, REG-2024-00003...
     Auto-incremented for audit trail

  ✨ Verification Token
     Format: a1b2c3d4e5f6...z9y8x7w6v5 (32 bytes, cryptographically random)
     Unique per recipient for secure verification

  ✨ Verification URL
     Format: https://verify.iucb.org/verify/a1b2c3d4e5f6...
     Personalized verification link for each recipient

  ✨ QR Code
     Format: PNG/SVG image of QR code
     Encodes verification URL for easy scanning

  ✨ Issue Date
     Value: Current date/time (auto)
     Used in certificate generation

  ✨ Expiry Date
     Value: Current date + 365 days (auto)
     Used in certificate generation

Total: 8 fields automatically generated per recipient!
