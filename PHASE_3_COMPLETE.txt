================================================================================
SMART MATCHING ALGORITHM
================================================================================

String Normalization:
  "Candidate Name" → "candidatename"
  "CandidateName" → "candidatename"
  "candidate_name" → "candidatename"
  "candidate-name" → "candidatename"
  All normalize to same form

Confidence Levels:
  100% - Exact match after normalization
   90% - Alias match (e.g., "Full Name" → candidate_name)
   70% - Partial match (e.g., "Name" contained in placeholder)
   50% - Word overlap
    0% - No match

Alias Detection:
  candidatename: student, participant, recipient, name
  email: emailaddress, emailid, mail, contact
  institutename: institute, organization, school, college
  course: coursename, program, training
  issuedate: date, issued, dateissued
  credentialid: credential, reference, id
  certificatenumber: certificate, certno, number
  trainer: instructor, facilitator, teacher
  duration: length, hours, days
  score: grade, marks, percentage, points
