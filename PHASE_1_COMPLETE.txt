ARCHITECTURE OVERVIEW

REQUEST FLOW:
  User clicks "Send Bulk Email" button
    ↓
  Navigate to /admin/training-institutes/bulk-email
    ↓
  Render BulkEmailCampaignPage with useExcelUpload hook
    ↓
  User selects Excel file
    ↓
  parseExcelFile() extracts recipients
    ↓
  validateRecipients() checks each record
    ↓
  Update state with results
    ↓
  Display UploadCard, SummaryCards, PreviewTable components

════════════════════════════════════════════════════════════════════════════════
VALIDATION ENGINE
════════════════════════════════════════════════════════════════════════════════

FILE VALIDATION:
  ✓ Format: .xlsx or .xls
  ✓ Size: Maximum 10 MB
  ✓ Structure: Valid Excel workbook with worksheet
  ✓ Content: Not empty, contains headers and data

RECORD VALIDATION:
  ✓ Candidate Name: Required, minimum 2 characters
  ✓ Email: Required, RFC 5322 format, unique
  ✓ Institute Name: Required, not empty

ERROR DETECTION:
  ✗ Missing candidate name           → INVALID
  ✗ Missing email                    → INVALID
  ✗ Missing institute name           → INVALID
  ✗ Invalid email format             → INVALID
  ✗ Duplicate email                  → DUPLICATE
  ✗ Empty row                        → Skipped
  ✗ Whitespace only                  → Skipped

STATUS TYPES:
  VALID   - Green badge, all required fields present and valid
  INVALID - Red badge, validation errors detected
  DUPLICATE - Orange badge, email already exists in file

USAGE INSTRUCTIONS
════════════════════════════════════════════════════════════════════════════════

1. NAVIGATE TO BULK EMAIL PAGE
   Training Institutes → Click "Send Bulk Email" button

2. PREPARE YOUR EXCEL FILE
   Create .xlsx file with columns:
   - Candidate Name (required, min 2 chars)
   - Email (required, valid format)
   - Institute Name (required)

3. UPLOAD FILE
   Drag file to drop zone OR click to browse and select

4. REVIEW RESULTS
   ✓ Check summary statistics
   ✓ Review validation results in table
   ✓ Search/sort to find errors
   ✓ Note any duplicate emails

5. FIX ERRORS (if any)
   ✓ Edit Excel file offline
   ✓ Fix validation errors
   ✓ Remove duplicate emails
   ✓ Re-upload file

6. PROCEED
   Click "Next" to go to Phase 2 (when implemented)
