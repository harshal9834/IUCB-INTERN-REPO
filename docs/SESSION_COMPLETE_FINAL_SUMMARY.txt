ISSUE RESOLVED
--------------
Excel Column Header Validation Bug - FIXED

USER PROBLEM:
  Excel files with 3 required columns (Candidate Name, Email, Institute Name) 
  were showing validation error: "Required Columns (1/3 found)"
  This blocked users from proceeding in the workflow.

ROOT CAUSE:
  The normalizeColumnName() function in ExcelRequirementsCard.tsx was not 
  properly converting all input formats to UPPERCASE_SNAKE_CASE for comparison.
  It only worked correctly for camelCase inputs, but failed for other formats.

SOLUTION:
  Completely rewrote the normalization pipeline to handle:
  - camelCase inputs (candidateName → CANDIDATE_NAME)
  - snake_case inputs (candidate_name → CANDIDATE_NAME)
  - Space-separated (Candidate Name → CANDIDATE_NAME)
  - Hyphen-separated (candidate-name → CANDIDATE_NAME)
  - Mixed formats with special characters
  - Edge cases with multiple spaces/hyphens
