SMART PLACEHOLDER REPLACEMENT
================================================================================

Algorithm:
  1. Get recipient data from first valid Excel row
  2. Find all {{...}} patterns in template
  3. For each placeholder:
     a. Look up mapped Excel column
     b. Get value from recipient
     c. If value exists → replace
     d. If unmapped → highlight red
     e. If no value → highlight red
  4. Track statistics
  5. Return modified HTML + warnings

Security:
  • HTML escaping for user data
  • Script tag detection
  • Event handler blocking
  • XSS protection
  • Safe dangerouslySetInnerHTML usage

Performance:
  • Single pass through HTML
  • O(n) complexity where n = placeholders
  • <50ms for average templates
  • No unnecessary re-renders
  • Debounced updates
