PROBLEM:
  When uploading an Excel file with campaign name, the backend returned:
  HTTP 400 - "Campaign name is required"

ROOT CAUSE:
  Multer's .single("file") method only extracts the "file" field.
  Other FormData fields like "campaignName" are completely ignored.
  
  Frontend sends:
    FormData {
      file: [File object],
      campaignName: "My Campaign"
    }
  
  Backend received:
    req.file: [File object] ✅
    req.body: {} ❌ (empty - campaignName missing!)

SOLUTION:
  Changed Multer configuration from:
    uploadExcel.single("file")
  
  To:
    uploadExcel.fields([
      { name: 'file', maxCount: 1 },
      { name: 'campaignName', maxCount: 1 }
    ])
