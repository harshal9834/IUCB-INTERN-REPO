═══════════════════════════════════════════════════════════════════════════════
EMAIL FLOW
═══════════════════════════════════════════════════════════════════════════════

1. Campaign Status = READY
2. Load Recipients Queue
3. For each recipient with generated certificate:
   a. Update Status: SENDING
   b. Generate Personalized Email HTML (Handlebars)
   c. Verify PDF Certificate Exists
   d. Compose Email with PDF Attachment
   e. Send via SMTP
   f. Capture SMTP Response (message ID, response, accepted, rejected)
   g. Update Recipient Status: SENT or FAILED
   h. Create Audit Log
   i. Continue with Next Recipient (never stop on failure)
   j. Apply Rate Limiting Delay
4. Update Campaign Statistics
5. Determine Final Status:
   • All sent: COMPLETED
   • Some failed: PARTIALLY_COMPLETED
   • All failed: FAILED
6. Create Campaign Completion Audit Log
